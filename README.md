# Shell Emulator

Эмулятор языка оболочки ОС с консольным интерфейсом (CLI).
Практическая работа по дисциплине «Конфигурационное управление»,
вариант №3.

## Общее описание

Программа имитирует работу в командной строке UNIX-подобной ОС.
Приглашение к вводу формируется на основе реальных данных ОС,
например `username@hostname:~$`.

Реализовано (этап 1 — REPL):

- консольный интерфейс (CLI);
- приглашение вида `username@hostname:~$`;
- простой парсер: команда и аргументы разделяются по пробелам;
- сообщения об ошибках (неизвестная команда, неверные аргументы);
- команды-заглушки `ls`, `cd` и команда `exit`.

Этап 2 — конфигурация:

- параметры командной строки `--vfs`, `--prompt`, `--script`;
- отладочный вывод всех параметров при запуске;
- стартовый скрипт: команды выполняются последовательно, на экране
  видны и ввод, и вывод; выполнение останавливается на первой ошибке.

## Команды

| Команда | Описание |
|---------|----------|
| `ls [args...]` | Заглушка: выводит своё имя и аргументы |
| `cd [args...]` | Заглушка: выводит своё имя и аргументы |
| `exit` | Завершает работу эмулятора |

Ошибки:

- `<cmd>: command not found` — неизвестная команда;
- `exit: too many arguments` — неверные аргументы `exit`.

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs PATH` | Путь к физическому расположению VFS |
| `--prompt TEXT` | Пользовательское приглашение к вводу в REPL |
| `--script PATH` | Путь к стартовому скрипту |

При запуске все параметры печатаются в виде строк `[debug] ...`.
Не заданный параметр отображается как `(not set)`.

## Стартовый скрипт

Текстовый файл, одна команда на строку. Пустые строки и строки,
начинающиеся с `#`, пропускаются. Каждая команда выводится после
приглашения, затем её результат — как в диалоге с пользователем.
При первой ошибке скрипт останавливается, эмулятор завершается
с кодом 1. Если скрипт не завершился командой `exit`, эмулятор
продолжает работу в интерактивном режиме.

Примеры: `examples/scripts/*.emu`.

## Требования

Python 3.8+. Внешние зависимости не требуются.

## Сборка и тесты

Сборка не нужна. Запуск тестов:

```
make test
```

или без make:

```
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Запуск

```
make run
```

или

```
PYTHONPATH=src python3 -m shell_emulator
```

## Скрипты реальной ОС

Каталог `scripts/` содержит shell-скрипты, вызывающие эмулятор:

| Скрипт | Что проверяет |
|--------|---------------|
| `scripts/stage2_params.sh` | Все параметры командной строки |

Запуск: `sh scripts/stage2_params.sh`.

## Пример использования

```
make run ARGS='--prompt "demo>" --script examples/scripts/basic.emu'
```

Интерактивный сеанс:

```
user@host:~$ ls -l /tmp
ls -l /tmp
user@host:~$ cd docs
cd docs
user@host:~$ foo
foo: command not found
user@host:~$ exit 1
exit: too many arguments
user@host:~$ exit
```
